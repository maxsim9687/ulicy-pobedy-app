# Улицы Победы – приложение

Школьный проект Максима Шумилова (7 «П»): три улицы Екатеринбурга, названные в честь участников Великой Отечественной войны – Громова, Гризодубовой и Рябинина.

- **Квест «Три улицы»** с картой Яндекса, геолокацией, трамваем № 16 и секретным словом.
- **AR-таблички**: виртуальные мемориальные доски стоят на улицах по GPS-координатам. Подойдите и наведите камеру – за каждую табличку дают блок знака «Хранитель памяти».
- **Герой рядом**: AR-фото с героем в полный рост.
- **Аудиогид** (озвучка ElevenLabs), подробные истории героев, викторина.

## Сборка

Всё собирается в GitHub Actions (`.github/workflows/build.yml`):

- `android/` – Kotlin + Jetpack Compose, CameraX, датчик вращения, GPS. Результат – `UlicyPobedy.apk`.
- `ios/` – SwiftUI + ARKit (выравнивание по компасу), проект генерируется XcodeGen. Результат – `UlicyPobedy.ipa` без подписи, устанавливается через Sideloadly или AltStore.
- `shared/` – общие данные (`content.json`), фото, аудио и карта.

Готовые файлы – в разделе Releases. Инструкция по установке: https://city.maxsim.space/app/
